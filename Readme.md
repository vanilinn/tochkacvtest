# Сегментация изображений для обнаружения труб

Данный проект включает в себя реализацию модели семантической сегментации для выделения участков труб на изображениях. Модель построена на основе архитектуры **U-Net** с бэкбоном **EfficientNet-B1**, и используется для выполнения сегментации с последующей постобработкой — нахождением окружностей вокруг выделенных областей.
